# Инструкции по работе над проектом

- Для каждого процесса проводить сквозную проверку от исходных условий до результата. Определять участников, источник входных данных, ответственность приложения и внешних сервисов, изменения состояния и исход при отказе.
- Для каждого процесса и подпроцесса явно указывать событие запуска, предусловия, обязательные начальные данные, их источники и исход при отсутствии обязательного входа.
- Для каждого действия приложения, которое читает или изменяет данные, показывать на процессной диаграмме компактный блок конкретных данных под действием и соединять его прямой стрелкой чтения или записи. Состав источников и направление обращения по каждому хранилищу уточнять в таблице.
- Функциональную модель оформлять в составе контекстной диаграммы, диаграммы декомпозиции функций и диаграмм потоков данных.
- Для каждого блока DFD указывать соответствующие функции программы по функциональной модели IDEF0.
- В архитектурных представлениях C4 указывать соответствие предметных компонентов функциям A1–A5.
- Диаграммы в Miro создавать из редактируемых фигур, подписей и соединителей.
- Порядок этапов определяет [рабочий план](PROJECT_PLAN.md). Правила подготовки материалов и согласования определяет [методика проектирования](<Методика проектирования.md>).
