# 02. Понятийный аппарат

## Назначение документа

- **Задача** — установить значения терминов предметной области бронирования авиабилетов.
- **Результат** — перечень терминов и проектных определений.
- **Использование** — согласование терминологии вербального описания, моделей, требований и испытаний.
- **Признак готовности** — существенные термины определены и последовательно применяются в документах.

## Термины и определения

Определения установлены в границах [замысла системы](01-system-concept.md) и применяются в [вербальном описании](02-domain-description.md).

| Термин | Определение |
| --- | --- |
| Аккаунт | Запись в приложении, связанная с учётной записью для входа, списком пассажиров и оформленными бронированиями. |
| Владелец аккаунта | Лицо, которое входит в личный кабинет, оформляет бронирования и осуществляет оплату с данного аккаунта. |
| Учётная запись для входа | Запись, создаваемая сервисом регистрации для последующей проверки учётных данных при входе. |
| Учётные данные | Сведения, которые проверяются при входе в аккаунт. |
| Регистрация | Создание учётной записи для входа и связанного с ней аккаунта приложения. |
| Сервис регистрации | Сервис, который создаёт учётную запись для входа и сообщает приложению результат регистрации. |
| Сервис проверки документов | Внешняя система, которая проверяет документы пассажиров, загруженные в личном кабинете, и сообщает приложению результат. |
| Подтверждённый документ пассажира | Документ пассажира, по которому получен положительный результат внешней проверки. |
| Личный кабинет | Область приложения, доступная после успешной проверки учётных данных и предназначенная для работы со списком пассажиров, бронированиями и билетами соответствующего аккаунта. |
| Пассажир | Лицо, для которого оформляется бронирование и на имя которого после подтверждения оплаты оформляется билет. |
| Список пассажиров | Совокупность лиц, добавленных в личном кабинете для последующего выбора при оформлении бронирования. |
| Реквизиты документа пассажира | Сведения, идентифицирующие документ пассажира при оформлении бронирования. |
| Прямой рейс | Запланированный перелёт из аэропорта отправления в аэропорт назначения без пересадки. |
| Место на рейсе | Место в салоне, предоставляемое пассажиру на конкретном рейсе. |
| Пассажирская вместимость рейса | Предельное количество пассажирских мест, предоставляемых для бронирования на конкретном рейсе. |
| Багажная вместимость рейса | Предельное количество мест багажа, которое может быть закреплено за бронированиями на конкретном рейсе. |
| Бронирование | Запись о поездке одного пассажира на конкретном рейсе, связанная с аккаунтом владельца и содержащая сведения о закреплённом месте, количестве мест багажа и текущем состоянии. |
| Платёжная попытка | Обращение к платёжному сервису для оплаты бронирования или дополнительных мест багажа, по которому ожидается либо получен окончательный результат. |
| Платёжный сервис | Внешняя система, через которую производится оплата и от которой поступает её результат. |
| Билет | Документ, оформляемый на пассажира после подтверждения оплаты бронирования и удостоверяющий приобретение перевозки. |
| Место багажа | Отдельная единица багажа, учитываемая в количестве багажа по бронированию. |
| Маршрутная квитанция | Документ, содержащий сведения об оформленном билете и маршруте поездки. |
| Смена места | Замена закреплённого места свободным местом на том же рейсе. |
| Отмена бронирования | Прекращение бронирования с освобождением закреплённых пассажирского места и мест багажа после подтверждения отмены. |
| Запрос на возврат оплаты | Обращение владельца аккаунта о возврате оплаты по отменённому бронированию, состояние которого учитывается отдельно от состояния бронирования. |
